# Голосовая цепочка: Parakeet → бот v4, затем v51

Состояние на 2026-10-09, рабочая машина (Windows, RTX 4090, i9-10900K). Здесь лежит всё, из чего собран бот v4:
списки фраз, транскрипты, скрипты, результаты проверок. Сам бот — в `models/coop-deberta-v3-ens3-v4`.

**Бот по умолчанию по-прежнему v31.** v4 и v51 — версии для цепочки «голос → распознавание → бот». v51 собрана тем же
способом, что v4, в тот же день; всё, что ниже раздела «v51», описывает v4 и сравнения, на которых выбран способ.

## v51: огонь, направления и «look at»

Владелец 2026-10-09 погонял v4 в C++-чате и попросил три вещи: приказы огня, отдельное намерение для простого
«attack» и направления («go down by stairs» и «go up by stairs» давали одну и ту же запись). Пока обучение ждало
GPU, добавил четвёртую: команду «look at …». Версия v5 (27 намерений, без «look at») описана и заморожена, но
не обучалась: v51 сменила её до первого обучения.

| | v4 | v51 |
|---|---|---|
| Намерений | 24 | 29: + `ATTACK`, `OPEN_FIRE`, `HOLD_FIRE`, `LOOK_AT`, `LOOK_AT_ME` |
| Реплики авторов, печатные | 633 | 903: прежние 633, 180 под спецификацию v5, 90 под v51 |
| Seed-команды, печатные | 580 | 801 |
| Транскрипты Parakeet | 1456 | 2064 |
| Всего обучающих фраз | 2669 | 3768 |
| Эпох | 12 | 12 |
| Гейт и порог | top, 0.50 | family, 0.62 |
| Правила мест | набор правил v3 | набор правил v4: у цели есть направление |
| Сборка | 18 обучений, 20 минут | 18 обучений, 28 минут |

Слепые реплики писали и читали агенты, видевшие только спецификацию: три автора, по два аннотатора на автора.
Прежние реплики перечитаны под новые спецификации: новое намерение получили три реплики (две `OPEN_FIRE`, одна
`LOOK_AT`), каждую прочитали ещё двое. Озвучены реплики авторов `r6` и `cs` и все новые seed-команды — теми же
наборами голосов, что для v4 (`export_v5.py`, `export_v51.py`, `synth_v5.py`, `synth_v51.py`).

### Проверка v51

Как у v4: каждая реплика предсказана моделями, которые не видели её ни в печатном, ни в озвученном виде; три сида
усреднены. Критерий — «попадание − 2 × чужое семейство». Полный вывод — `score_v51.log`.

| Что получает классификатор | Все реплики `r6` и `cs` (602) | Прежние 422, на которых проверялась v4 | у v4 на них было | Новые 180 |
|---|---|---|---|---|
| Печатный текст | 91.0 | 89.8 | 90.0 | 93.9 |
| Голоса Windows → Parakeet | 90.7 | 89.1 | 88.9 | 94.4 |
| Kokoro, английские голоса → Parakeet | 90.7 | 89.6 | 87.2 | 93.3 |
| Kokoro, голоса других языков → Parakeet | 88.9 | 87.9 | 86.0 | 91.1 |
| VCTK, дикторы из обучения → Parakeet | 70.6 | 68.7 | 65.6 | 75.0 |
| VCTK, дикторы, которых не было в обучении → Parakeet | 71.9 | 69.0 | 69.2 | 78.9 |

На последней строке (невиданная реплика, невиданный диктор): попадание 82.2, чужое семейство 5.1%, действие на
не-приказ 7.4%. Реплики автора `stt` (301, только печатно): критерий 88.4.

Новые намерения — сколько реплик с этим намерением выбрано точно:

| | `ATTACK` | `OPEN_FIRE` | `HOLD_FIRE` | `LOOK_AT` | `LOOK_AT_ME` |
|---|---|---|---|---|---|
| Печатный текст | 16 из 16 | 15 из 18 | 18 из 18 | 20 из 20 | 11 из 12 |
| Голоса Windows | 16 из 16 | 15 из 18 | 18 из 18 | 20 из 20 | 11 из 12 |
| VCTK, невиданные дикторы | 14 из 16 | 13 из 18 | 16 из 18 | 18 из 20 | 9 из 12 |

Худшая ошибка для этих намерений — перепутать `OPEN_FIRE` и `HOLD_FIRE`. На печатном тексте и чистых голосах её
нет; на невиданных дикторах VCTK она случилась дважды: одна реплика `HOLD_FIRE` понята как `OPEN_FIRE` и одна
наоборот.

Оговорки те же, что у v4, и ещё две:

- Авторы, аннотаторы и перечитывающие — ИИ. Все 270 новых реплик единогласны по намерению, месту и направлению у
  автора и двух аннотаторов; это слабее, чем звучит.
- Проверка мягче, чем «без одного автора»: реплики автора отложенной реплики есть в обучении.

### Сборка v51

```
python export_v5.py;  pwsh synth_windows_v5.ps1;  venv\Scripts\python synth_v5.py
python export_v51.py; pwsh synth_windows_v51.ps1; venv\Scripts\python synth_v51.py
foreach ($v in 'v5','v51') {
  $env:STT_LINES = "lines_$v.json"
  foreach ($s in 'clean','kokoro','kokorox','vctkA','vctkB') { venv\Scripts\python run_stt.py parakeet-0.6b-v2 $s --tag "_$v" --stream-n 0 }
  $env:STT_LINES = "seeds_$v.json"
  foreach ($s in 'seedclean','seedkokoro','seedkokorox','seedvctkA') { venv\Scripts\python run_stt.py parakeet-0.6b-v2 $s --tag "_$v" --stream-n 0 }
}
pwsh run_build_v51.ps1        # 18 обучений, по четыре процесса; около 4,5 ГБ видеопамяти на процесс
python score_v51.py           # таблица и models/coop-deberta-v3-ens3-v51/bot_config.json
```

Экспорт для C++ и сверка — как для любой версии (HANDOFF.md, раздел 5, шаг 3). Спецификации, слепые реплики и
правила направлений описаны в HANDOFF.md, раздел 4, «Модель v51».

| Решение | Кто и когда |
|---|---|
| Микрофон по кнопке; минимальный процессор i9-10900K | владелец, 2026-10-07 |

| Бота учить на том, что услышал Parakeet, с известными метками | идея владельца, 2026-10-08 |

## Чем v4 отличается от v31

Архитектура та же: три DeBERTa-v3-base, усреднение вероятностей. Отличается обучающий набор и число эпох.

| | v31 | v4 |
|---|---|---|
| Реплики авторов, печатные | 633 | 633 |
| Seed-команды, печатные | 580 | 580 |
| Транскрипты Parakeet | нет | 1456 |
| Всего обучающих фраз | 1213 | 2669 |
| Эпох | 20 | 12 |
| Гейт и порог | family, 0.62 | top, 0.50 |

Транскрипты — это то, что Parakeet услышал, когда реплики авторов `r6` и `cs` (422) и seed-команды (580) читали
синтезированные голоса. Каждый транскрипт получает метку своей фразы. Перед классификатором текст приводится к
строчным буквам и убирается конечная точка; знаки препинания внутри остаются. Транскрипт, совпавший с уже
имеющейся фразой, второй раз не добавляется. Реплики автора `stt` не озвучивались: они сами изображают вывод
распознавания и участвуют только в печатном виде.

## Результат проверки v4

Каждая реплика предсказана моделями, которые не видели её ни в печатном, ни в озвученном виде (пять частей, три
сида усреднены). Критерий — «попадание − 2 × чужое семейство».

| Что получает классификатор | Попадание | Чужое семейство | Критерий, `r6` и `cs` (422) | Критерий, только `r6` (211) |
|---|---|---|---|---|
| Печатный текст | 94.8 | 2.4% | 90.0 | 89.6 |
| Голоса Windows → Parakeet | 93.6 | 2.4% | 88.9 | 87.7 |
| Kokoro, английские голоса → Parakeet | 92.9 | 2.8% | 87.2 | 88.2 |
| Kokoro, голоса других языков → Parakeet | 91.7 | 2.8% | 86.0 | 86.3 |
| VCTK, дикторы из обучения → Parakeet | 78.4 | 6.4% | 65.6 | 70.1 |
| VCTK, дикторы, которых не было в обучении → Parakeet | 79.1 | 5.0% | 69.2 | 71.1 |

Последняя строка — главная: невиданная реплика, невиданный диктор, порог подобран не на ней.

Порог 0.50 подобран по правилу проекта на транскриптах «обучающих» голосов. При нём бот действует на 10–12%
не-приказов на чистых голосах. На невиданных дикторах VCTK порог меняет картину так:

| Порог (гейт top) | Критерий | Чужое семейство | Действует на не-приказ |
|---|---|---|---|
| 0.50 | 69.2 | 5.0% | 6.1% |
| 0.62 | 69.7 | 3.3% | 6.1% |
| 0.80 | 67.1 | 2.1% | 3.0% |
| 0.90 | 65.6 | 1.7% | 1.5% |

Какой порог ставить в игре — открытое решение владельца.

## Оговорки

- Все голоса синтетические. На живой речи, настоящем микрофоне и игровом шуме ничего не проверено.
- Проверка мягче, чем «невиданный автор» из документов проекта: реплики одного автора похожи между собой.
- Набор `wav_noisy` (розовый шум на 10 дБ тише речи) владелец счёл неправдоподобно жёстким; выводы на нём не строить.
- Бот выучил и искажённые фразы: «throw in the other room first» (так Parakeet услышал «drone the other room first»)
  для него теперь `DRONE`.
- Сборки и сравнения сделаны после того, как все реплики были прочитаны; по правилам проекта все цифры здесь
  «после подгонки» (запись в `../frozen.txt`).

## Что сравнивалось и что вышло

### Движки распознавания

Бот v31 как есть, 422 озвученные реплики. Бот учился на этих же репликах, поэтому таблица годится только для
сравнения движков между собой.

| Движок | Голоса Windows | Kokoro, английские | Kokoro, другие языки | VCTK | Память | После отпускания кнопки |
|---|---|---|---|---|---|---|
| **Parakeet 0.6B v2** | 99.1 | 98.6 | 93.6 | 72.3 | 706 МБ | 202 мс на 2 потоках, 145 мс на 4 |
| Moonshine Medium Streaming | 97.6 | 96.4 | 88.6 | 66.6 | 353 МБ | 7 мс, до 300 мс в худших 5% |
| Zipformer kroko 2025 | 95.5 | 94.8 | 90.8 | 61.1 | 163 МБ | 43 мс |
| Moonshine Small Streaming | 98.3 | 97.2 | 89.1 | 57.6 | 214 МБ | 7 мс, до 196 мс |
| Moonshine Tiny Streaming | 92.7 | 94.5 | 84.8 | 54.3 | 97 МБ | 7 мс, до 73 мс |

Ещё проверены и отброшены Whisper tiny.en (медленный, не точнее) и Parakeet 110M (задвоенные буквы в тексте).
Moonshine по умолчанию занимает все ядра; одним потоком его ограничивает переменная `MOONSHINE_ORT_SINGLE_THREAD`.
Если отдать Moonshine запись целиком с паузой перед речью, он дописывает в начало «Yeah» или «You»; при подаче
звука по ходу речи этого нет (`lead_test.py`).

### Данные и рецепт

Сравнения на одной модели (сид 0), проверка на 211 репликах `r6`, критерий на невиданных дикторах VCTK.

| Вопрос | Вариант | Критерий |
|---|---|---|
| Нужны ли транскрипты в обучении | без них / с ними (только `r6` и seed-команды) | 31.8 / 37.9 |
| Нужны ли реплики `cs` | без / с | 37.9 / 60.2 |
| Нужны ли реплики `stt` (печатные) | без / с | 60.2 / 63.5 |
| Убирать ли регистр и знаки препинания | оставить / убрать | 60.2 / 53.1 |
| Сколько эпох | 8 / 12 / 20 | 56.9 / 68.7 / 63.5 |

Отсюда состав v4: все три автора, транскрипты, знаки препинания на месте, 12 эпох. Без `cs` печатный текст тоже
падает с 84.8 до 61.1. Вариант на 5 эпох не посчитан.

Первая проба идеи шла на транскриптах Zipformer и на целиком невиданном авторе (`exp_stt_aug.py`): прибавка от
+1.4 до +7.1 пункта на каждом наборе голосов, печатный текст не пострадал.

## Как повторить

Нужны два окружения: своё для речевых инструментов (`requirements.txt`) и обучающее с torch (HANDOFF.md, раздел 2).
Команды из этой папки, PowerShell.

1. Скачать и распаковать модели (в git их нет):
   - в `models/`: `https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8.tar.bz2`
   - в `tts/`: `…/releases/download/tts-models/vits-piper-en_GB-vctk-medium.tar.bz2` и `…/tts-models/kokoro-multi-lang-v1_0.tar.bz2`
2. Списки и звук:
   ```
   python export_lines.py lines.json
   python export_seeds.py seeds.json
   pwsh synth_windows.ps1
   venv\Scripts\python synth_accents.py
   venv\Scripts\python synth_train.py
   ```
3. Транскрипты Parakeet, по одному запуску на набор:
   ```
   $env:STT_THREADS = '2'
   foreach ($s in 'clean','kokoro','kokorox','vctkA','vctkB') { venv\Scripts\python run_stt.py parakeet-0.6b-v2 $s --stream-n 0 }
   $env:STT_LINES = 'seeds.json'
   foreach ($s in 'seedclean','seedkokoro','seedkokorox','seedvctkA') { venv\Scripts\python run_stt.py parakeet-0.6b-v2 $s --stream-n 0 }
   ```
4. Сборка в обучающем окружении, 18 обучений; на RTX 4090 по четыре одновременно — около 20 минут:
   ```
   python build_v4.py oof 0      # и так же 1, 2
   python build_v4.py final 0    # и так же 1, 2
   python score_v4.py            # таблица и models/coop-deberta-v3-ens3-v4/bot_config.json
   ```
5. Экспорт для C++ и сверка — как для любой версии (HANDOFF.md, раздел 5, шаг 3).

Синтез Piper не повторяется побитно, поэтому новые записи и транскрипты будут немного отличаться от лежащих здесь.
Набор `wav_noisy` получен разовой командой и скриптом не воспроизводится.

## Чего ещё нет

- Проверки на живой речи.
