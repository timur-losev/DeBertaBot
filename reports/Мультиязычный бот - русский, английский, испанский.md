# Мультиязычный бот: русский, английский, испанский

Исследование и план, 2026-10-22. Владелец: «Мне нужен русский, английский, испанский языки, какой-то тест, под какой,
как переводить, все варианты разрешения и обучать, сколько времени займет, какие варианты обучения».

## Коротко

- **Сервер переводить не нужен.** Всё, что зависит от языка, работает у игрока на клиенте: распознавание речи,
  классификатор, места, ответы, голос. На сервер уходит приказ без языка: намерение, координаты, id предмета.
- **Речь.** Одна модель понимает все три языка: **Parakeet TDT 0.6B v3**. Это тот же движок и тот же размер, что
  сейчас (v2), только у v2 один английский. Есть экспорт для sherpa-onnx (int8), лицензия CC-BY-4.0.
- **Рекомендую путь «перевод на входе, таблицы на выходе».**
  - Русская или испанская фраза переводится на английский прямо на клиенте.
  - Дальше работает весь нынешний английский конвейер, без изменений.
  - Ответы бота берутся из заранее переведённых таблиц строк, а не из живого перевода.
  - Почему этот путь: правила мест и предметов и их проверки Python/C++ не меняются.
- **Первый шаг — замер, 1–1,5 дня.** Тесты на трёх языках, Parakeet v3, переводчик, классификатор v61 как есть.
  Цифры покажут, нужно ли обучение и какое.
- **Сроки:**
  - работающий минимум без обучения — 3–4 дня;
  - с обучением и встройкой в игру — 6–9 дней работы;
  - обучение идёт на GPU параллельно с остальной работой.

## 1. Что сейчас зависит от языка

| Звено | Где работает | Сейчас | Что нужно для ru/es |
|---|---|---|---|
| Распознавание речи (STT) | клиент, coop_cli | Parakeet TDT 0.6B v2, только английский | Parakeet v3 (25 языков, есть ru/es/en) |
| Цепочка (роутер + Qwen3-1.7B) | клиент, линия v5x | английский | перевод перед ней, или переобучить на трёх языках |
| Классификатор (3×DeBERTa) | клиент | английский | перевод перед ним, или многоязычная модель |
| Места (`locations`, правила v7) | клиент, Python и C++ | английские слова | перевод перед ними, или словари ru/es |
| Предметы (`items`, i2) | клиент, Python и C++ | английские глаголы и слова | то же |
| Планировщик: вопросы и отказы | клиент | английские шаблоны (~47 фраз) | таблицы строк ru/es |
| Ответы бота (`LINES`) | клиент | 168 английских фраз на 56 намерений | таблицы строк ru/es |
| Фразы игры (контакт, оружие, «Target down») | клиент и сервер | английские строки в C++ | таблицы строк ru/es (локализация UE) |
| Голос бота (Piper) | клиент | английский голос VCTK | голоса Piper ru и es |
| Сервер (приказ, исполнение) | сервер | без языка | ничего |

Всего около 250–350 строк ответов.

**Падежи.** В русском сложнее всего места в ответах. «Иду к {place}» требует дательного падежа: «к красной
лестнице». Названия мест на карте английские («red stairs»). Значит, у каждого места нужны русские формы по
падежам, а у шаблона — нужный падеж. В испанском только род и артикль: «la escalera roja».

## 2. Варианты решения

### A. Перевод на входе, английский конвейер, таблицы строк на выходе (рекомендую)

```
речь ru/es → Parakeet v3 → текст ru/es → ПЕРЕВОДЧИК → английский → [нынешний конвейер] → приказ
                                                                         ↓
                                                     ответ: id шаблона + параметры → таблица ru/es → Piper ru/es
```

Подварианты переводчика:

| | Модель | Скорость (CPU, оценка) | Плюсы | Минусы | Лицензия |
|---|---|---|---|---|---|
| A1 | Opus-MT (Marian), отдельно ru→en и es→en | ~20–50 мс на фразу | маленькие (~300 МБ), быстрые | дословны на сленге («закинь флешку» → «throw a flash drive») | ru→en CC-BY-4.0, es→en Apache-2.0 (сверить с карточками) |
| A2 | M2M-100 418M, одна на все языки | ~100–200 мс | одна модель, MIT | для этих пар не лучше Opus-MT, медленнее | MIT |
| A2′ | NLLB-200 | ~100–200 мс | лучшее качество из открытых | **некоммерческая лицензия: в продаваемую игру нельзя** | CC-BY-NC |
| A3 | наш декодер цепочки (Qwen3-1.7B), переобученный: вход на трёх языках, выход — английские приказы | 37 мс GPU, 0,4–0,5 с CPU | перевод, разбиение составных приказов и контекст за один шаг; сленг выучит | нужно обучение; на CPU медленно | Apache-2.0 |
| A4 | Canary-1B-v2: речь сразу в английский текст | ~1B параметров, медленнее Parakeet | один шаг вместо двух (STT + перевод) | поддержка sherpa-onnx не подтверждена; заменить STT целиком | CC-BY-4.0 |

### B. Родной многоязычный классификатор, без перевода

- **Модель:** классификатор на многоязычной модели вместо DeBERTa-v3. Варианты: **mDeBERTa-v3-base** (MIT,
  ~280M) или **mmBERT-base** (MIT, 307M, 1800+ языков).
  - mDeBERTa в C++ дешевле: её токенизатор SentencePiece Unigram того же типа, что наш (`tokenizer.h`).
  - mmBERT потребует нового токенизатора в C++.
- **Плюсы:** нет задержки и ошибок перевода в намерении.
- **Минусы:** места и предметы — английские словесные правила. Нужны словари и правила ru/es в Python и в C++ с
  проверками совпадения. Это самая большая работа из всех вариантов.

### C. Гибрид

- Многоязычный классификатор (B) определяет **намерение**.
- Перевод (A1) нужен только для **мест и предметов**: правила читают английский перевод.
- Ошибка перевода тогда задевает только место, не сам приказ.

### Сравнение

| | Работы | Риск ошибок | Задержка | Что меняется в правилах |
|---|---|---|---|---|
| A (A1) | меньше всего | ошибки STT + перевода складываются | +20–50 мс | ничего |
| A (A3) | обучение декодера | ниже на сленге | +37 мс GPU / +0,5 с CPU | ничего |
| B | больше всего | ниже в намерении | 0 | словари мест и предметов ru/es в Python и C++ |
| C | средне | ниже в намерении | +20–50 мс | ничего |

## 3. Распознавание речи

- **Parakeet TDT 0.6B v3:**
  - 25 европейских языков, среди них английский, русский и испанский;
  - язык определяет сам; размер и скорость как у v2;
  - есть int8-экспорт для sherpa-onnx (коммит «Export nvidia/parakeet-tdt-0.6b-v3 to sherpa-onnx»);
  - код coop_cli тот же (TDT transducer), меняется только папка модели.
- **Риск, проверить первым — твой английский.** v2 учили только на английском, и на нём она может быть лучше. Кроме
  того, v3 на английском с русским акцентом может принять речь за русскую. Решение: язык игрока в настройках
  (en / ru / es). Для en остаётся v2, как сейчас, для ru/es работает v3.
- Canary-1B-v2 (вариант A4) умеет и распознавание, и перевод речи в английский. Это кандидат для сравнения, не для
  первого шага.

## 4. Как переводить

**Вход (фраза игрока).**
- Сначала A1 (Opus-MT) как база: быстро, без обучения.
- Перед ним маленький словарь игрового сленга на ru/es: «смок» → smoke, «флешка» / «флеш» → flashbang,
  «зачистить» → clear, «пушить» → push.
- Дальше по цифрам: дообучить Opus-MT на наших командах (вариант O-2), либо декодер A3.

**Выход (ответы бота).**
- Без живого перевода: таблицы строк.
- Около 300 строк × 2 языка переводит сильная модель заранее.
- Русский проверяешь ты; испанский — выборочно, лучше носитель.
- Места в ответах — с падежами (раздел 1).
- Голос: Piper. Русские голоса irina, denis, dmitri, ruslan; испанские es_ES и es_MX. У каждого голоса своя лицензия,
  проверить перед выбором.

**Мультиплеер.** Если ответ бота слышат другие игроки, по сети идёт id строки + параметры, а не текст. Каждый клиент
произносит его на своём языке.

## 5. Тесты: какие и под что

| Тест | Под что | Как делается | Объём |
|---|---|---|---|
| T1. Набранные фразы ru и es | понимание приказа без ошибок речи | слепые авторы (ИИ, по спецификации, не видя обучающих данных) пишут фразы сразу на своём языке, с игровым сленгом; два аннотатора на каждую фразу, как для английских наборов | 3 автора × 60 фраз × 2 языка = 360 |
| T1′. Перевод английских слепых фраз | тот же смысл на трёх языках: прямое сравнение языков | английские слепые наборы переводит сильная модель; не тот переводчик, что в конвейере, иначе завышено | ~150 × 2 |
| T2. Синтетическая речь ru и es | весь конвейер: речь → STT → перевод → классификатор | T1 и T1′ озвучивают голоса, которых нет в обучении: ru — Piper ru и Windows Irina/Pavel; es — Piper es и Kokoro es | ~1000 записей |
| T3. Живая речь | настоящая цель | ru: ты наговариваешь 30–50 приказов в игре; es: носитель, если есть, иначе только T2 | 30–50 + ? |
| T4. Регрессия английского | ничего не сломали | тесты v61 и твои английские фразы через ту же сборку; отдельно Parakeet v3 на твоём английском | как в v61 |
| T5. Места | куда идёт приказ | точность цели планировщика на фразах с местами («к красной лестнице», «al segundo piso») | часть T1/T2 |
| T6. Ответы | качество таблиц строк | ru — ты, es — выборочно | ~300 строк |

**Метрики** те же, что в исследованиях v61 и decider:
- точность;
- точность и полнота действий по правилу бота (семейный гейт, 0,66);
- неверные приказы и «повтори»;
- задержка каждого звена на i9-10900K;
- всё по каждому языку отдельно.

- Около 4,8 тыс. строк и затравок переводит сильная модель несколькими «стилями» (разговорный, сленг, коротко). Так
  не выходит дословный перевод одного переводчика.
- Проверка обратным переводом и выборочно глазами.
- Тестовые наборы (T1) пишут отдельные слепые авторы, а не этот перевод.

## 7а. Проверка: Qwen на каждой фразе, без маршрутизатора (2026-10-22)

Вопрос владельца: «один из вариантов — всегда держать Qwen включённым и пропускать текст через него без
маршрутизатора».

**Набор:** 41 русский и 41 испанский случай. Есть простые приказы, сленг («закинь флешку», «поставь смок»), места и
метка, составные приказы, поправки и повторы, по 2 фермерских/строительных. Текст набран так, как его отдаёт
распознаватель: строчными, без точки в конце. Скрипты лежат в папке сессии: `chain_ml_test.json`,
`chain_ml_run.py`, `qwen_translate_probe.py`.

| Вариант | Перевёл на английский | ru: верна вся последовательность / первый приказ (из 39) | es: то же (из 39) |
|---|---|---|---|
| Декодер цепочки v59 (наш Qwen3-1.7B с LoRA), без маршрутизатора | 0 | 10 / 11 | 13 / 13 |
| То же + в инструкции «always write the orders in English» | 0 | 10 / 11 | 13 / 13 |
| Обычный Qwen3-1.7B без нашего обучения, промпт «переведи как игровой приказ», затем классификатор v61 | все, кроме одной | **30 / 33** | **28 / 31** |

**Наш декодер не переводит.** Его научили переписывать простую фразу как есть, и он делает это и с русской, и с
испанской. Добавка к инструкции ничего не меняет. Составные приказы он всё же делит, но на исходном языке («primero
tira una flash y luego entra» → «tira una flash» / «entra»).

**Обычный Qwen3-1.7B переводит хорошо** («закинь флешку в комнату» → «Throw a flashbang into the room», «поставь смок
на лестнице» → «Put smoke on the stairs», «construye un muro» → «build a wall»). Ошибки:
- **составной приказ** пишет одной английской строкой («Go up and shoot the car»), и классификатор берёт только
  первый приказ;
- **сленг и оружие:**
  - «перезарядись» → «Charge up»;
  - «возьми дробовик» → «take the frag»;
  - «пригнись» → «Get ready»;
  - «ve a mi marcador» → «Check my score»;
- **потеря смысла:**
  - «a mi señal entra en la sala» → «I'll enter the room» («по моему сигналу» пропало);
  - «no dispares» осталось непереведённым;
- **поправка с местом:** «нет не туда к двери» после «иди к окну» → «Go to the window». Намерение верное, место нет:
  оценка по намерению это не видит.

«Ещё раз» и «otra vez» он переписывает в «Fire at the window again» → OPEN_FIRE: по смыслу это верно.

**Вывод.**
- Держать Qwen на каждой фразе имеет смысл только после обучения (O-4): вход на трёх языках, выход — английские
  приказы по одному на строку, со сленгом, «по моей команде», местами и поправками.
- Основа уже на ~75–80% даже без обучения, поэтому обучение должно довести её до уровня английского.
- Время на фразу: GPU ~37 мс (llama.cpp, Q4), CPU 0,4–0,5 с. Здесь (transformers, bf16, без оптимизаций) вышло
  ~0,3 с на случай.

## 7г. Союз «и»: цепочка v63 (2026-10-22, вечер)

Владелец после игры на v62: «бот не понимает союз и не выполняет команды последовательно. Хотя если я скажу потом, тогда он
сделает две команды».

- **Причина.** Декодер v62 переводил «подпрыгни и стреляй» одной английской строкой ("jump up and shoot"), и
  классификатор видел в ней одну команду. С «потом» он всегда делил. В английском было то же самое: на 50 фразах
  владельца с контекстом цепочка v62 дала 28/50 (у v59 было 45/50). Корень в обучающих строках: одиночные приказы с «and»
  внутри переписывались как есть, а коротких пар «приказ и приказ» было мало.
- **Декодер v63** (`chains7_v63.py`): строки v62 и плюс:
  - убраны одиночные строки, в которых классификатор читает две разные команды из разных семей (199 строк и их
    переводы);
  - 2500 коротких пар на каждый язык, с and / и / y;
  - тест из 150 пар на язык, составленных из отложенных фраз.
- **Маршрутизатор v63** (`router_v63.py`): английские пары отдаются декодеру. Маршрутизатор v59 отправлял "reload and
  cover me" классификатору.

| Набор | v62 | v63 |
|---|---|---|
| Пары en / ru / es (не видел при обучении) | 84.7 / 88.7 / 88.7 | 99.3 / 98.0 / 96.0 |
| Английские пары через маршрутизатор | 77.3 | 99.3 |
| 50 фраз владельца с контекстом, весь мозг | 28/50 | 43/50 |
| Слепые наборы ru / es (цепочки, контекст) | 78.0 / 80.0, 82.7 / 78.7 | 79.3 / 78.7, 80.0 / 80.0 |

- **Цена.**
  - Английский набранный контекст через маршрутизатор: 86.0 → 82.7. Виноват маршрутизатор v63: он отдаёт классификатору
    некоторые фразы без «and», которые опираются на прошлые ("okay now you check it"). Со вторым зерном вышло 84.0, то
    есть часть потери — случайность.
  - С маршрутизатором v59 фразы владельца дают 41/50 вместо 43, поэтому оставлен v63.
  - Новая ошибка: лишнее деление уточнения. "watch the stairs and shoot if someone comes" становится двумя приказами.
- **Не исправлено.**
  - Пары из одной семьи: "go up by the stairs and jump down" (MOVE_TO + JUMP) по-прежнему одна строка. Пары для обучения
    брались только из разных семей. Это 3 из 7 оставшихся ошибок на фразах владельца.
  - «Стреляй» декодер пишет как "should …": так распознавание слышит "shoot" у владельца. Бот v61 читает это как
    OPEN_FIRE.
  - Вопрос «ну чё там» классификатор читает как HOLD_ANGLE ("what's up there"). Так было и с v62; это задача для
    классификатора.
- **В игре.**
  - Мозг v6x переустановлен с цепочкой v63 (`deploy_brain.ps1 -Chain coop-chain-v63`, 22:02).
  - Проверки цепочки 160/160.
  - `multilingual.txt` проходит. «прыгни и подойди ко мне» → JUMP, затем FOLLOW_ME; «иди ко мне сюда и прыгни» →
    FOLLOW_ME, затем JUMP; «подпрыгни и стреляй» → JUMP, затем OPEN_FIRE; «salta y ven aquí» → JUMP, затем FOLLOW_ME;
    "reload and cover me" → RELOAD, затем COVER_ME; "come here and jump" → FOLLOW_ME, затем JUMP.

## 9. Решения за тобой

1. **Продаётся ли игра.** От этого зависят лицензии: NLLB нельзя, у голосов Piper надо смотреть каждый.
2. **Язык игрока в настройках или по речи автоматически.** Рекомендую в настройках: тогда для английского остаётся
   v2, которая лучше понимает твой английский.
3. **GPU для перевода и декодера.** С GPU вариант A3/O-4 быстрый; без него перевод только A1.
4. **Кто проверит испанский:** носитель или только синтетика.
5. **Отвечает ли бот голосом на языке игрока,** и слышат ли другие игроки его на своём языке.
